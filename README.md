# GPT-2 Text Generation

## Project Overview
This project demonstrates text generation using the GPT-2 language model from Hugging Face Transformers in Google Colab.

## Features
- Uses pretrained GPT-2 model
- Generates text from custom prompts
- Demonstrates NLP text completion
- Implemented in Python using Transformers library

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- PyTorch

## Sample Prompts
- Artificial intelligence is
- The best way to learn programming is
- In the future, robots will
